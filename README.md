# MegaEnchant

PaperMC向けのMinecraftプラグインです。アイテムスタック・自動補充、ランダムテレポート、モブ捕獲、専用GUI機能を搭載しています。
A PaperMC plugin featuring item stacking, auto-refill, random teleportation, mob capture, and custom GUI menus.

## 主な機能と使い方

### 1. メインGUI
- `/megaenchant` コマンドで専用のGUIメニューを開くことができます。

### 2. アイテムスタック & 自動補充
- インベントリ内のアイテム整理や自動補充が行えます。

### 3. ランダムテレポート
- プレイヤーをランダムな座標へ安全にテレポートさせます。

### 4. モブ捕獲 (CaptureBall)
- キャプチャーボールを使ってモブを捕獲・持ち運びができます。
